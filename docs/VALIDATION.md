## 已知限制

- 真实手机访问问题不能仅凭桌面、手机尺寸模拟或Windows WebKit宣布彻底解决。
- 手机的浏览器下载、长按保存与相册入口不一致；当前不承诺自动入相册。
- 尚无服务端统计；原始工程的事件接口为不上传数据的占位实现，不能称分析看板已完成。
- 题目语义和覆盖面仍需要继续审核，已有重复题反馈就是一个反例。
- 构建记录有Node版本声明、Vite CJS与Next组件`use client`指令相关警告；并非零警告工程。
- 本地后端测试、数据库方案或迁移文件不证明真实数据库已配置、迁移或上线。

4. **隐私友好的统计**：在确定告知和数据保留规则后，再设计最小化事件，不默认上传逐题答案。
5. **专题扩展**：消费、网络、旅行人格需要先完成题库与验收，不仅增加入口。

### 未来指标的定义（仅方案）

- 主测完成率：完成主测的去重会话 / 开始主测的去重会话。
- 隐藏面进入率：进入加测的去重会话 / 完成主测的去重会话。
- 图片生成成功率：成功生成图片的次数 / 发起生成的次数。
- 网站链接复制率：成功复制链接的去重会话 / 查看主测结果的去重会话。

点击下载不等于保存成功，复制链接不等于实际转发，实际转发也不等于带来访问。没有对应观测能力时，不应把前一个事件当作后一个成果。
